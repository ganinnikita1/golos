## [0.1.2] — 2026-11-11

Первый публичный выпуск (0.1.1 не использовался: в собранном архиве нашёлся
служебный `__pycache__` от PyInstaller с путём сборочной машины).

### Security

- Сборка проверяет бандл на пути сборочной машины и **падает**, если они найдены
  (`packaging/verify_bundle.py`); `__pycache__`/`*.pyc`-мусор из `dist` вычищается
  до публикации.
- **Проверка целостности модели.** Ревизия GigaAM-v3 фиксируется на неизменяемом
  commit SHA, SHA256 всех файлов сверяется с манифестом
  `golos/asr/model_manifest.json` **до** импорта remote-кода. При несовпадении
  модель не загружается — чужой код не исполняется. Скачивание из неизвестных
  репозиториев запрещено без явного `asr.allow_unverified_model`.
- **Валидация конфига.** `gigaam_repo`/`gigaam_dirname` проверяются на безопасный
  формат — нельзя увести каталог модели за пределы `models_dir` (path traversal).
- **Проверка endpoint'ов.** Облачный ASR и LLM-полировка отказываются отправлять
  ключ/данные по HTTP на внешний хост; `http` разрешён только для localhost.
- **Приватность путей.** В интерфейсе, `--diagnose`, `selftest` и на скриншотах
  пути показываются как `%APPDATA%`/`%LOCALAPPDATA%`/`%USERPROFILE%`; «Скопировать
  сведения» обезличено.
- **История.** Переключатель «Хранить историю распознаваний»; при выключенном
  оверлее текст диктовки не попадает в системное уведомление.
- **CI/поставка.** GitHub Actions закреплены по SHA, `persist-credentials: false`,
  `GITHUB_TOKEN` read-only, Dependabot, release workflow с `SHA256SUMS` и
  Sigstore-аттестацией; в репозитории защищены main и теги (`v*`).
- `.gitignore` дополнительно закрывает `.env`, `*.key`, `*.pem`, `.credentials*`.

### Added

- Офлайн-диктовка для Windows на GigaAM-v3 `e2e_rnnt` (MIT): русский язык,
  пунктуация, заглавные буквы и нормализация чисел прямо из модели.
- Глобальная горячая клавиша (`Ctrl+Alt+Space` по умолчанию), режимы `toggle` и
  `push_to_talk`, отмена по `Esc`; хук `WH_KEYBOARD_LL` без прав администратора.
- Вставка текста в любое приложение двумя способами: прямой Unicode-ввод (по
  умолчанию) и через буфер обмена с восстановлением содержимого.
- Приватность буфера: распознанный текст исключается из журнала Windows (Win+V) и
  облачной синхронизации, при невозможности восстановления буфер очищается.
- Оверлей записи с индикатором уровня, таймером и предпросмотром текста; не
  перехватывает фокус и пропускает клики.
- Трей-меню: старт/стоп/отмена, статус модели, настройки, история, автозапуск, выход.
- Окно настроек: горячая клавиша, микрофон с проверкой, движок распознавания,
  постобработка и словарь замен, LLM-полировка, вставка/буфер, история, оформление.
- Мастер первого запуска: микрофон → скачивание модели → готово.
- Постобработка русского текста: пунктуация/регистр, словарь замен (регистронезависимый),
  слова-паразиты, произносимые знаки, типографика («ёлочки», тире, «ё»).
- Опциональная LLM-полировка через любой OpenAI-совместимый сервер (DeepSeek по
  умолчанию), с безопасным fallback на исходный текст.
- Опциональные движки faster-whisper (CPU int8) и облачный ASR
  (OpenAI/Groq/custom endpoint).
- История распознаваний с поиском, копированием и повторной вставкой.
- Диагностика окружения: `python -m golos.cli selftest`, `Golos.exe --diagnose`.
- Сборка: PyInstaller one-dir (`packaging/build.ps1`) и установка в профиль
  пользователя с ярлыками (`packaging/install.ps1`), проверка хешей бандла.
- Бенчмарк русского ASR и отчёты: `reports/asr_bench.md`, `reports/asr_implementation.md`.
- Тесты: 300+ unit/integration + сквозной e2e (реальная модель → вставка в окно),
  CI на GitHub Actions (Windows, Python 3.13).

### Changed

- Вставка по умолчанию — прямой ввод без буфера обмена (по запросу: диктовка не
  должна попадать в буфер). Режим буфера остался опцией и стал приватным.
- Модель загружается в фоне при старте (после мастера первого запуска), приложение
  доступно сразу.
- Логи пишутся в `%APPDATA%\Golos\logs` с ротацией; добавлен fallback каталогов
  данных, если `%APPDATA%` недоступен.

### Fixed

- Remote-код GigaAM грузится без ложной зависимости от `pyannote` и без `ffmpeg`.
- Конфиг и история читаются корректно, даже если JSON сохранён с BOM.
- Аудио: ресемплинг в 16 кГц, устойчивость к переполнению буфера и смене устройства.
