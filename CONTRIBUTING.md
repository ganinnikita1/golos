# Как помочь проекту

Спасибо, что хотите улучшить «Голос»! Ниже — как предложить изменение так, чтобы
его было легко проверить и принять.

## Что можно сделать

* **Баги и странности распознавания** — заведите issue по шаблону: версия Windows,
  движок/вариант модели, что сказали, что распознали, фрагмент лога
  (`%APPDATA%\Golos\logs\golos.log`, без личных данных).
* **Улучшения** — issue с описанием сценария: что неудобно, как должно быть,
  какой результат считается успехом.
* **Код** — исправления, новые движки ASR, улучшения постобработки, UI.
* **Документация** — примеры, скриншоты, переводы.
* **Тестовые данные** — реальные записи с транскрипцией (без персональных данных
  и без нарушения лицензий) для бенчмарка `tools/eval_ru.py --real-manifest`.

Пожалуйста, не присылайте персональные записи, API-ключи и приватные тексты.

## Процесс

1. Создайте issue (или найдите существующее).
2. Форкните репозиторий и создайте ветку от `main`:
   `git checkout -b feat/short-description` или `fix/short-description`.
3. Внесите изменение, добавьте/обновите тесты.
4. Прогоните быстрые тесты: `.\.venv\Scripts\python.exe -m pytest tests -q`.
5. Обновите [CHANGELOG.md](CHANGELOG.md) в разделе `Unreleased`, если изменение
   заметно пользователям.
6. Откройте pull request по шаблону: что и зачем, как проверяли, скриншоты для UI.

## Требования к pull request

* Один PR — одна логическая правка.
* Тесты не ломаются; для нового поведения добавлены тесты.
* Публичные контракты (`golos/controller.py`, `golos/asr/base.py`,
  `golos/text/base.py`, `golos/inject/base.py`, `golos/hotkey/base.py`) либо не
  меняются, либо изменение отражено в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
* Стиль: Python 3.13, type hints, до 100 символов, `logging` вместо `print`.
  Русские тексты — в UI и сообщениях об ошибках, код — по-английски.
* Коммиты — Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`,
  `perf:`, `chore:`.

## Окружение и тесты

```powershell
python -m venv .venv
python tools\bootstrap_env.py
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe -m pytest tests -m slow     # модель/GUI, если доступны
```

Подробности — [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

Отправляя PR, вы соглашаетесь, что ваш вклад распространяется под лицензией MIT,
как и весь проект.
