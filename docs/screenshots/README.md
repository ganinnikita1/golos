# Скриншоты интерфейса «Голос»

Снимки сделаны из демо-режима (`python -m golos.ui.screenshots`) через
`QWidget.grab()`; оверлей наложен на нарисованный рабочий стол, чтобы показать
его поверх другого приложения. Пакеты и внешние скриншотеры не используются.

| Файл | Что показано |
|------|--------------|
| `overlay_recording.png` | оверлей-«пилюля» во время записи: бары уровня, таймер, распознанный текст |
| `overlay_result.png` | оверлей после вставки текста |
| `settings_main.png` | настройки → «Основные»: горячая клавиша, запуск, оверлей, тема |
| `settings_microphone.png` | настройки → «Микрофон»: устройство, проверка, параметры аудио |
| `settings_recognition.png` | настройки → «Распознавание»: движок и загрузка GigaAM-v3 |
| `settings_text.png` | настройки → «Текст»: обработка, слова-паразиты, словарь замен |
| `settings_polish.png` | настройки → «Полировка LLM» |
| `settings_about.png` | настройки → «О программе»: версия, пути, лицензии |
| `settings_light_main.png` | светлая тема оформления |
| `history.png` | окно истории распознаваний с поиском и предпросмотром |
| `onboarding_welcome.png` | мастер первого запуска, шаг «Знакомство» |
| `onboarding_microphone.png` | мастер первого запуска, выбор и проверка микрофона |
| `onboarding_model.png` | мастер первого запуска, скачивание модели |
| `tray_menu.png` | меню иконки в трее с горячей клавишей и статусом модели |

Пересобрать все снимки:

```
cd repos\golos
.\.venv\Scripts\python.exe dev_env.py -- .\.venv\Scripts\python.exe -m golos.ui.screenshots
```
